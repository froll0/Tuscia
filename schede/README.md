# SCHEDE DA RIPRODURRE

- [Scheda del casato](scheda-casato.md) — una per casato
- [Scheda del congiunto](scheda-congiunto.md) — una per personaggio di famiglia
- [Scheda del faccendiere](scheda-faccendiere.md) — una per faccendiere
  *(la parte inferiore non si mostra ad alcuno, neppure al patrono)*
- [Scheda della terra](scheda-terra.md) — una per ciascuna terra posseduta
- [Scheda dell'esercito](scheda-esercito.md) — una per esercito in campo
- [Scheda della trama](scheda-trama.md) — una per trama; si consegna coperta
  all'Arbitro

Si raccomanda inoltre che ogni casato tenga un quaderno di **ricordanze**: il
registro delle nascite, delle morti, delle nozze, degli acquisti, dei debiti e
delle offese non ancora vendicate.
